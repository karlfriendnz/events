Foundation & data layer

Local MySQL runningDedicated MySQL 8.4 container (fm-new, port 3400), isolated from the legacy-import work so it can’t be reset from under us.✅
Typed middle layer (the seam)App → small typed API → MySQL. Swapping the backend later = change one layer, not every screen.✅
