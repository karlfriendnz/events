🤪 Numpty — 1 / 4 — a real finding

171 of 199 write routes return a 500 on garbage input instead of a clean 400. The routes validate output (parse-on-output) but throw an unhandled ZodError on bad input, which surfaces as a 500 with a stack. Empty-body create and wrong-type fields both 500.

Not fixed tonight (a safe fix touches all ~199 routes / adds a global error handler — the backend team's route-hardening domain; it's already the security audit's MEDIUM-1). Recommended fix: a Nitro error hook mapping ZodError → 400 + safeParse on input. Low user impact today (real forms send valid shapes); matters for a public API.
